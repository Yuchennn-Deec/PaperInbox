论文收件箱 0.5.0 · Prompt自定义分类与界面修订

本包包含Windows便携EXE和配套Zotero连接插件。
本次仅打包，没有安装新版、退出旧程序或修改正式文库。

更新方式
1. 解压完整ZIP到一个固定文件夹，不要直接从ZIP里运行EXE。
2. 退出托盘里的旧版论文收件箱。
3. 在Zotero插件管理器中从文件安装PaperInbox-Zotero-Bridge-0.5.0.xpi，按提示重启Zotero。
4. 运行同一包内的PaperInbox.exe。EXE和连接插件需配套使用0.5.0。
插件支持Zotero9，已在9.0.6独立测试库验证；本包没有自动安装器。
现有服务商、模型、当前Windows用户加密保存的密钥和待确认任务沿用原存储位置。
不要把他人的设置文件或密钥复制进程序目录；本包不含私人配置。

路径由Prompt定义
进入“API 与模型 → 分类 Prompt（可编辑）”，填写你希望的分类规则并保存。
API会在结构化响应的collections字段中返回完整分类路径。程序校验路径格式，不再自动插入材料化学式层。
你不必编写JSON模板；程序会附上固定输出格式、已有分类参考和论文提取文本。
自定义规则不注入材料通式目录，可用于材料、物理、计算机、法学等不同领域。
默认规则保留化学通式＋研究主题两套分类，主题路径直接使用主题名，例如：
按化学通式/MO（二元氧化物）/CuO
按主题/磁关联
同一个Zotero条目可归入多条路径，不会因此产生两份论文。

示例一：只按主题，不使用材料层
“按论文研究主题分类，只生成按主题/主题名形式的路径。
主题采用磁关联、二维反铁磁体等研究内容，不在路径或主题名前添加材料名称、化学式。
已有分类仅供参考；遵循以上路径规则。”

示例二：计算机论文
“按机器学习子领域分类，如机器学习/表示学习/对比学习。
按正文实际内容选择一到三条路径，不使用化学式或材料分类。
标签描述任务、方法及阅读优先级。”

规则按服务商分别保存，切换服务商会切换到其已保存规则。
留空或点击“恢复默认双分类”后保存，可使用本包内置默认规则；默认原文另附。
保存、恢复默认、历史分类选择都不会调用API，也不会重新分析当前论文。
修改后的Prompt用于下一次主动“API 分析所选”。“测试连接”只测试连通性。
有效API路径优先采用；只有使用默认规则且API没有返回可用路径时，才保留内置材料分类作为回退。
自定义规则返回缺失或非法路径时，分析结果会保留在“待核对/分类路径”，可手动修正，无需为已有结果重复调用API。
路径格式：最多80条，每条最多240字符、5层，每层1至80字符；用/分层，不允许空层、点或双点层和控制字符。
标签可使用普通标签或自定义前缀，不再局限于材料主题标签。

核对与可选材料助手
“按 Prompt 的路径”模式保留API完整路径，材料输入字段默认隐藏。
可直接编辑分类路径，每行一条；“恢复 API 路径”回填本次已保存的API路径，不会再次请求API。
需要时可选“化学通式 + 研究主题”“仅化学通式”“仅研究主题”，填写材料与主题后点击“生成分类路径”。
材料助手的主题路径也是按主题/主题名，不再形成材料与主题的组合目录。
最终点击“确认放入 Zotero”后才复制PDF入库，并按偏好在Zotero阅读器打开。原文件保留。

历史分类与旧分析
历史模块可搜索主题、化学式或路径，按分类类型和来源筛选，跨筛选多选，并替换或追加。
Zotero已有的其他学科分类也可以选择；最近记录仅在最终确认入库后保存，最多200条。
刷新Zotero目录是带本机认证的只读操作，不调用模型、不创建文献。
历史列表保留已有真实路径；若主动选择旧的材料嵌套主题路径，会按所选路径保留，可在核对窗口手改。
旧版尚未确认的默认分类可本机去除主题路径中的材料层，无需付费重跑API。
迁移前备份state.json.before-flat-topics-v4，并保留书目信息、来源哈希和原分析理由。
已确认、自定义、历史选择及Prompt返回的路径不会被材料迁移静默覆盖；正式Zotero目录本轮不做重排。

界面修订
圆角背景完整重绘，清除方形底色；输入框采用细描边，单行内容和下拉框居中。
修正年份、条目类型、生成方式及API参数被嵌套固定行高裁切的问题。
核对页内容可纵向滚动，底部确认按钮保持可见；窄窗口自动纵向排列。
Prompt和高级连接设置展开后会滚到可见区域，搜索及筛选控件使用统一样式。

运行与验证
下载检测沿用文件通知、后台扫描和1秒稳定窗口，只监测所选下载目录第一层。
只有你主动分析时才发送提取文本，最终确认后才入库。关闭主窗口仍在托盘运行。
三种API协议使用本机模拟响应验证，未调用真实付费API。
独立Zotero9.0.6库验证完整Prompt路径、普通标签、已有目录复用、附件查重、文件完整性和自动打开。
界面检查覆盖标准尺寸、窄窗口、圆角外无黑底及1.5倍布局缩放模拟；未修改系统缩放设置。
详细结果和文件校验值见验证记录.json。截图使用测试数据，不代表正式文库操作。
